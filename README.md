# Engen-Tech plugin marketplace

Plugins for Claude Code, GitHub Copilot, Codex and pi, published as one marketplace named `engen-tech`.

This repo holds no plugins yet. Each plugin arrives through a release of its product repo; see [docs/design.md](docs/design.md). Install lines and plugin sets follow once the first plugins are released.

Do not edit `plugins/`, the catalogs, `package.json` or `plugins.lock.json` by hand: every release checks the whole tree and fails on a hand edit.
